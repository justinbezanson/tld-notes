# General

## Always regenerate wayfinder with --with-form
resources/js/routes and resources/js/actions are gitignored and generated by @laravel/vite-plugin-wayfinder. Never run `php artisan wayfinder:generate` without `--with-form` — it strips the `.form()` helpers and breaks `npm run types:check` (CI bails). Use `npm run build`, `npm run dev`, or `php artisan wayfinder:generate --with-form --no-interaction`.
