Each table has 3 columns, Type, Item, Console Name. I want to build a JSON file out of these tables.

The section titles are the title attributes of each table. 

The category names are the values of the Type Column. If the category name contains a hyphen "-" that indicates a sub name. The part before the hyphen is the category name and the part after is the sub name.

The item names are the values of the Item column.

The item ids are the values of the Console Name column.

Save the json output to /home/justin/projects/tld-notes/docs/items.json

{
	"sections": [

				{
				"name": "item name",
				"id": "item id"
				}
			]
			}
		]
		}
		
	]
}
